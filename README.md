# Guitarla

A small guitar catalog front-end built with React and Vite, practicing component composition and
UI state (Header, Guitar cards, Footer) styled with Bootstrap.

## Stack

React 19, Vite, Bootstrap.

## Running it locally

```bash
npm install
npm run dev
```

Open the local URL Vite prints in the terminal.

## Available scripts

| Command | What it does |
|---|---|
| `npm run dev` | Starts the dev server |
| `npm run build` | Production build |
| `npm run preview` | Serves the production build locally |
| `npm run lint` | Lint |
